# Nisha Portfolio

Open `index.html` in a browser to view the site. To put it online, upload this whole folder
(GitHub Pages, Netlify, Vercel or any hosting) and keep the folder structure as it is.

    index.html            page content and structure (HTML)
    css/style.css         all design, colours, layout and animations (CSS)
    js/script.js          all behaviour: menu, theme switch, nisha.js window, background (JavaScript + GLSL shader)
    images/               profile photo and project screenshots
    favicon.svg / .ico    browser tab icon (apple-touch-icon.png is the phone home-screen icon)

To change text, edit `index.html`. To change colours, edit the variables at the top of `css/style.css`.
To change a project link, find the project in `index.html` and edit its `href`.
